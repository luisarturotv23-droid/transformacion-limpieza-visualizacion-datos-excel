# 📊 Limpieza, transformación y visualización de datos con Excel

## 📌 Descripción

Proyecto de preparación y visualización de datos realizado utilizando **Microsoft Excel y Power Query**, a partir de un conjunto de datos de títulos de Netflix.

El proyecto se enfoca en la **limpieza y transformación de los datos mediante Power Query** y posteriormente en su **organización y visualización utilizando Excel**.

## 🛠️ Herramientas utilizadas

* **Microsoft Excel**
* **Power Query**
* **Lenguaje M**

## 🔄 Proceso

**Datos originales → Limpieza → Transformación → Visualización**

### 1. 🧹 Limpieza y transformación de datos

Se utilizó **Power Query** para realizar diferentes pasos de limpieza y transformación sobre los datos originales, con el objetivo de estructurar la información y dejarla preparada para su utilización en Excel.

Los pasos aplicados pueden consultarse en las siguientes imágenes:

* 🖼️ [Pasos aplicados en Power Query — Parte 1](POWER_QUERY/IMAGES/Pasos_Aplicados_1.png)
* 🖼️ [Pasos aplicados en Power Query — Parte 2](POWER_QUERY/IMAGES/Pasos_Aplicados_2.png)

También se incluye el código **M** generado durante el proceso de transformación:

* 💻 [Código M — Limpieza de Datos](POWER_QUERY/Limpieza_Datos.txt)

### 2. 📊 Visualización y uso de Excel

Una vez realizada la limpieza y transformación, los datos fueron utilizados en **Excel** para organizar la información y realizar visualizaciones sencillas que facilitan su consulta e interpretación.
